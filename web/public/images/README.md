# StudyMind illustration assets

The StudyMind illustrations are AI-generated; the diagrams in the interface are original SVG. The three newly supplied square step illustrations were received as JPEGs and converted to WebP at quality 80 with metadata stripped. The clay-style empty course-map illustration is also optimized as WebP. The Open Graph artwork is PNG at exactly 1200×630.

All image components reserve space with explicit dimensions and responsive `sizes`. Only the hero is prioritized; the other page images are lazy-loaded. Meaningful illustrations have descriptive alt text, decorative backgrounds use empty alt text and are hidden from assistive technology, and failed images fall back to a brand-gradient block.
